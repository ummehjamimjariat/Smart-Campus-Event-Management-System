# Smart Campus Event Management System

## Default Logins
| Email | Password | Role |
|---|---|---|
| admin@campus.edu | admin123 | ADMIN |
| events@campus.edu | org123 | ORGANIZER |
| Register your own | any | STUDENT |

## Run in VS Code
1. Open the SmartCampus folder in VS Code
2. Install "Extension Pack for Java" by Microsoft
3. Open src/com/smartcampus/Main.java
4. Click Run above the main method

## Features
- Login / Registration (Student & Organizer)
- Admin Dashboard: users, events, registrations, logs
- Organizer Dashboard: create events, view attendees, update status
- Student Dashboard: browse events, register, cancel registrations
- Data saved to data/ folder as CSV files
